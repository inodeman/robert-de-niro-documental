# Robert De Niro — El hombre que desaparece

Documental independiente de **15 minutos**, en **español** y en **inglés**.

No está afiliado a Robert De Niro, a sus representantes ni a los estudios. No usa fotogramas de las películas. Habla de ellas y muestra **fotografías reales** con licencia libre (Creative Commons y CC0), acreditadas al final de cada video.
